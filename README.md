# Battle Arena 3D

Prototipo web 3D con Three.js, personajes articulados proceduralmente, escenario urbano detallado, cámara en tercera persona y controles de escritorio.

## Ejecutar

Abre `index.html` desde un servidor local o activa GitHub Pages.

## Controles

- WASD: movimiento
- Shift: correr
- Espacio: saltar
- Ratón: apuntar
- Clic: disparar

## Desarrollo

- Personajes construidos con grupos jerárquicos y pivotes articulares.
- Animación procedural basada en velocidad.
- Entorno PBR estilizado generado con primitivas y materiales procedurales.
- Datos locales mediante `localStorage`.
