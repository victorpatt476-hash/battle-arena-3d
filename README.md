# Battle Arena 3D

Prototipo web 3D preparado para GitHub Pages y CrazyGames.

## Controles

- **WASD:** mover
- **Shift:** correr
- **Espacio:** saltar
- **Ratón:** apuntar
- **Clic:** disparar

El juego usa Three.js por CDN, escenas y personajes articulados generados proceduralmente, texturas Canvas, iluminación PBR y guardado local.
